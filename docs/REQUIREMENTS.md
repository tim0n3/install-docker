# Requirements

## Must have
- A Linux host with systemd (the service manager)
- Root access (sudo)
- Network access to `https://download.docker.com`
- One of these package tools: apt or dnf

## Supported OS families
- Ubuntu
- Debian
- RHEL family: RHEL, CentOS, Rocky, Alma
- Fedora

## Not supported by this script
- Windows or macOS
- Offline installs
- Systems without systemd
- SLES or OpenSUSE
- Distros not listed above
